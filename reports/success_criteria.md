# Success Criteria: P(county outage | storm)

Revised 2026-10-27 during deliverable review. This replaces the numerical targets recorded on 2026-10-25. Initial logistic-regression validation results already exist, so this revision is **not a pre-training commitment**. Existing notebook outputs and W&B runs retain their historical checks; rerun evaluation to apply this policy. The 2025 test labels were not used in this review.

Unit and target: county x storm episode, positive = at least 5% of customers out within 24 hours (see [modeling-table summary](04_modeling_table_summary.md)). Train on 2017-2023, select models on validation (2024), then evaluate the selected model once on test (2025).

## Measured reference baseline

Source: [naive_rules_validation.csv](baseline_tables/naive_rules_validation.csv), generated by [notebook 05](../notebooks/05_baseline_models.ipynb) using `naive_rules()` and `evaluate()` in [src/evaluation.py](../src/evaluation.py). Values below are rounded for display; checks use predictions at full precision on the same evaluation rows.

| Rule | PR-AUC (average precision) | ROC-AUC | Brier | Brier skill | Recall at top 10% |
|---|---:|---:|---:|---:|---:|
| Always predict training rate | 0.164821 | 0.500000 | 0.138209 | -0.004026 | 9.2773% |
| Storm family rate | 0.311540 | 0.718476 | 0.124579 | 0.094993 | 23.1641% |
| County history rate | 0.367712 | 0.747168 | 0.123843 | 0.100337 | 26.9336% |
| **Storm family rate x county history (reference)** | **0.469056** | **0.804057** | **0.111560** | **0.189567** | **32.5781%** |

The family rule uses the highest training outage rate among storm families present in an episode. County history uses `hist_outage_rate`, constructed from training labels. The reference prediction is `clip(family_rate * hist_outage_rate / training_positive_rate, 0, 1)`. It combines storm type and county history without fitting an ML model.

PR-AUC here means scikit-learn average precision, not trapezoidal integration. Brier is the mean squared probability error. Brier skill is `1 - model_brier / (p_eval * (1 - p_eval))`, where `p_eval` is the observed evaluation positive rate. This constant-rate denominator is a scoring normalization, not a deployable prediction learned from validation labels. It differs from the training-rate rule: validation prevalence is 0.164821, giving a denominator of about 0.137655, while the training-rate rule has Brier 0.138209.

Top-10% recall ranks probabilities, selects `ceil(0.10 * n)` rows, and divides selected positives by all positives. Ties retain input row order. For 31,064 validation rows and 5,120 positives, 3,107 rows are flagged; the reference catches 1,668 positives (32.5781%). The theoretical maximum is 3,107 / 5,120 = 60.6836%. Constant predictions have arbitrary tie-based recall (9.2773% here), not a meaningful risk ranking.

## Success means improving on the reference

| Check | Requirement | Current validation reference |
|---|---|---:|
| Ranking (primary) | Average precision strictly above the reference on the same rows | 0.4690555266 |
| Probability accuracy | Brier no higher than the reference (equivalently, Brier skill no lower) | Brier 0.1115602542; skill 0.1895665580 |
| Prioritization | Recall at the same top-10% selection budget at least as high as the reference | 0.32578125 |

All three checks must hold for `passes_all_validation`. Matching the reference is not sufficient for the primary ranking check. The targets come from a reproducible comparator, not an assumed improvement margin. This establishes empirical value over a simple rule; it does not establish readiness for utility operations.

Report a paired 95% bootstrap interval for the average-precision gain, resampling whole `episode_id` groups to preserve within-episode dependence. The implementation uses 1,000 resamples and seed 42. These are analysis conventions, not empirically derived performance targets. An interval above zero supports an improvement claim; an interval spanning zero means the gain remains uncertain. It is reported separately from the three baseline checks.

Report calibration curves, overall and decile probability gaps, ROC-AUC, precision at top 10%, and average precision by year, storm family and FEMA region. Subgroup tables compare against the same reference within each group and include sample sizes and positive rates. Groups without both classes are omitted, so these tables cannot establish that every group performs well. There is no justified universal subgroup margin or calibration tolerance yet.

For the final 2025 evaluation, compare the selected model and the training-derived reference on the same test rows; report the same metrics and changes from validation. Do not tune on test results or impose the former arbitrary 0.05 year-to-year PR-AUC tolerance.
